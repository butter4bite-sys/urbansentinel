# Pune Marketplace Update — 19 November 2026

The marketplace now uses **eight individually named Pune business listings plus Diligent Enterprises**, correcting earlier generic placeholders. See `MARKETPLACE-CONTRACTOR-STATUS.md` for public contacts, source URLs and activation requirements.

All nine start as **public listings, not confirmed partnerships**. The Owner Dashboard can mark a business a confirmed Urban Sentinel partner only when its identity has been checked and actual partnership consent has been recorded. Callback tracking additionally requires an explicitly enabled referral account.

The website can import or refresh these names for existing installations without overriding owner-approved partners. For fresh installations, the default business login binds to Diligent Enterprises rather than the first directory entry. It does not imply the contractor has agreed to a relationship.
