# Connected House update

- Before/After no longer displays separate photographic comparisons. Both views use the same interactive Canvas house and camera.
- House type, floors, length and width are editable in the shared 3D house controls and persisted via `us4.property`. Duplex, apartment, school and shop receive type-specific architectural details.
- X-Ray Your House now mounts the same interactive house, thermal overlay, open-roof view, appliance placement and shared inputs.
- Electricity data remains linked through `us4.calc.electricity`.
- Original view temporarily removes passive roof/shading improvements without overwriting the saved scenario. AC and fan loads remain present; this is an illustrative comparison, not a calibrated engineering model.
- No changes to City Intelligence, AQI, Temperature Maps, or Marketplace.
